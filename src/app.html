Home
오늘 할 카드 수와 진도. 상황 칸을 누르면 그 상황만 학습. 왼쪽 위 로고·뒤로가기로도 이동
카드
한국어를 보고 소리 내 말한 뒤 탭 → 정답·발음 확인 → 다시어려움알맞음쉬움 중 선택. 버튼 아래 숫자가 다음 복습 시점. 이미 아는 건 알아요, 필요 없는 건 스킵 — 카드에서 빠져요
퀴즈
뜻·표현·듣기·빈칸 4가지 + 랜덤. 틀리면 한 번 더 고를 기회. 중간에 나가기로 저장(이어 풀기) 또는 기록 지우고 나가기. 틀린 문제는 카드 복습에 바로 추가
말하기
마이크를 누르고 말하기. 초록은 맞음, 빨강은 놓침. 베트남어는 '성조 빼고' 점수만 높으면 성조 연습이 필요
사전
상황 탭은 옆으로 밀거나 펼치기. 성조 없이 검색 가능 (bao nhieu). ★ 즐겨찾기. 상태(새것·읽음·학습 중·앎·스킵)로 거르고, 항목을 열어 상태를 바꿔요. 오른쪽 위 약자는 출처 — 출처 범례를 누르면 그 출처만 보이고 어떻게 만든 건지 설명이 나와요
모드
카드·말하기·퀴즈 위의 모드로 상황·레벨·문장/단어·★만 고르기. 지금 모드는 블록으로 표시
계정
설정 → 계정에서 이메일 + PIN 6자리로 로그인하면 휴대폰·PC 어디서든 진도가 이어져요
소리
단어 풀이의 단어를 누르면 그 단어만 재생. 천천히는 0.7배속

갤럭시 폴드에서

  • 베트남어 소리에 성조가 없거나 안 나오면: 휴대폰 설정 → 일반 → 텍스트 음성 변환(TTS) → 엔진 설정에서 베트남어 음성 설치 (설정 검색창에 'TTS')
  • 말하기(음성 인식)는 Chrome 권장. 처음 한 번 마이크 허용
  • 앱처럼 쓰기: Chrome ⋮ → 홈 화면에 추가 / 삼성 인터넷 ≡ → 현재 페이지 추가 → 홈 화면
  • 로그인하지 않으면 진도는 이 브라우저에만 저장돼요. 설정 → 계정에서 로그인하거나 가끔 백업
